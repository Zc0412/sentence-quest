# SentLeap 微信小程序

原生 TypeScript + WXML + WXSS。微信开发者工具使用 TypeScript 编译插件；开发与类型检查依赖安装在仓库根目录，不需要在开发者工具中构建 npm。

## 界面与页面

- 题库：尚无练习进度时按 `LibraryEmptyGlass.dc.html` 显示新手引导和第一题示例；已有完成、错题、输入记录或前进位置时按 `LibraryGlass.dc.html` 显示当前题目与掌握进度；“全部”进入题库列表，支持短语／单词切换、搜索、分类、最近练习和进行中筛选，内置三个离线测试库，并可展示云端已登记的题库。
- 首页进入练习：按 `StartMotionGlass.dc.html`、`ContinueMotionGlass.dc.html` 播放单次按钮回弹、扫光、箭头位移和卡片展开，真实练习页导航、题目卡、键盘依次入场。支持防连点、离页取消、跳转失败恢复和测量失败回退；微信原生页面切换与动效衔接需在真机核对。
- 练习：按 `MainGlass.dc.html` 实现彩色背景、字母方格、音标、英美音切换、XP、掌握率与毛玻璃键盘。内置键盘支持大小写和删除，拼对自动切词；提供提示、跳过、上一句/下一句和完成解析。长句区域独立滚动，键盘固定底部并预留安全区。
- 统计：按 `StatsGlass.dc.html` 实现所有题库的总掌握率、累计 XP、输入数、正确数、正确率和本周（周一至周日）的练习柱状图。点击生成分享海报进入独立页面，预览真实学习数据并可发送给好友或保存到相册。项目尚无可用的小程序码，海报使用品牌引导文案。
- 错题：按 `MistakesListGlass.dc.html` 和 `MistakesEmptyGlass.dc.html` 显示列表或空状态。自动收录拼错、提示和跳过的题目并标注原因；独立正确完成复习后移除。旧记录未保存原因时显示“待复习”。可从“我的”进入。
- 我的：按 `MyGlass.dc.html` 实现资料卡、连续练习天数、真实 XP / 掌握数 / 正确率及毛玻璃设置列表。昵称可编辑并保存在本机；支持发音口音、切词后自动发音、字母提示、错题入口及微信原生意见反馈。学习提醒尚未接入订阅消息，保持关闭并说明当前限制。

首页、练习页、统计页与我的页使用自定义导航避让微信胶囊；首页、统计页与我的页使用悬浮底栏，离开后恢复原生 TabBar。输入统计从此版本开始记录到本地，不推算旧版输入历史；每个新增或替换的字符计一次，按对应位置判定正确，删除、字母提示不计数。练习页显示本次练习的统计，统计页显示累计值。

## 导入与联网

开启自动发音时，短语练习每次进入题目先朗读一遍整句，切词后继续朗读当前词；沿用所选英音或美音，关闭自动发音时不自动播放。

句子闯关和单词测试（三个单词）仅在开发版（`envVersion === 'develop'`）显示；体验版、正式版及无法读取环境信息时隐藏。精选短语仍可使用，已有学习记录保留。

1. 在仓库根目录执行 `npm install`，然后在微信开发者工具导入 `miniprogram/`。项目已开启 TypeScript 编译插件。
2. 本地体验可使用默认测试配置；真机预览 / 上传请在 `project.config.json` 使用你自己的小程序 AppID。
3. 内置三个离线测试词库：精选短语（20 题）、句子闯关（11 题）和单词测试（3 词）。`npm run sync:miniprogram` 同步这三个题库及共享规则。其他题库从云托管接口读取。
4. 发音通过云托管 Hono 服务请求有道发音服务，口音 `1` 为英音，`2` 为美音。云托管调用不使用客户端直接下载音频；保持开发工具 `urlCheck` 开启。

发音依赖云开发环境、已部署的云托管服务以及有道发音服务的可用性。尚未提供登录、云同步、订阅消息提醒和网页端完整分类 / 分组管理界面。自动发音失败时静默跳过；手动点击发音失败会提示检查云开发配置。

## 微信云开发

在微信开发者工具打开 `miniprogram/`，使用与项目 AppID 关联的账号开通云开发并创建环境；在云开发控制台复制环境 ID，填入 `config.ts` 的 `cloudEnvId`。小程序启动时会调用 `wx.cloud.init({ env: cloudEnvId })`。环境 ID 不是 AppSecret，不要把 AppSecret 或服务端密钥写进小程序代码。

配置为空时跳过初始化，离线练习仍可用。将 `cloud-service/` 部署为微信云托管服务，并在 `config.ts` 的 `cloudServiceName` 填入实际服务名（当前为 `sentleap-service`）。小程序通过 `wx.cloud.callContainer` 请求服务，具体部署、权限和验证方式见 [云托管服务说明](../cloud-service/README.md)。发音返回 Base64 音频并写入本地临时文件，页面关闭时清理；学习进度仍保存在本机。

“全部题库”先显示内置及上次缓存的目录，再刷新云端目录；读取题库后按内容 SHA-256 缓存在本地。缓存受设备空间限制，缓存写入失败时仍可进行本次练习。云端不可用时内置题库仍可练习。旧云题库重新上线时应保持题库 ID 和条目顺序不变，以便继续使用本地进度。

### 上传题库到云存储

需同时安装根目录及 `cloud-service/` 依赖，并配置云托管对象存储及 MySQL 连接信息，详见 [云服务配置](../cloud-service/README.md#部署)。本机必须能连接目标 MySQL。

上传工具在开发电脑运行，将 JSON 写入微信云托管对象存储 COS，并将文件 ID 和元数据登记到云托管 MySQL。先在目标 MySQL 数据库执行 `cloud-service/sql/001-dictionaries.sql` 创建 `dictionaries` 表，再在 `cloud-service/.env` 配置 `WX_CLOUD_ENV_ID`、`COS_BUCKET`、`COS_REGION` 和 MySQL 连接信息。云托管需开启开放接口服务的对象存储能力；上传时由开放接口动态获取临时 COS 凭据，不需要在本机配置固定存储密钥。

在仓库根目录执行以下命令，先校验并预览：

```sh
npm run upload:dictionary -- --file web/public/dictionaries/words/CET4_T.json --id CET4_T --kind word --label CET-4
```

确认题库 ID、数量和环境后，在同一命令末尾加 `--upload` 执行上传。默认使用 `miniprogram/config.ts` 中的环境 ID；如需其他环境，可指定 `--env <环境ID>`。单词库使用 `--kind word`，短语库使用 `--kind phrase`；可通过 `--category <分类>` 指定分类。工具验证字段但不改写文件或条目顺序，并将内容 SHA-256 加入云路径，更新内容会产生新路径。

上传成功后，工具将云存储返回的 `fileID` 与题库 ID、名称、分类、类型、条目数、SHA-256、云路径和时间写入 MySQL `dictionaries` 表。表主键为题库 ID；同 ID 已存在时只更新这些字段，保留其他管理字段和原始创建时间。云存储与数据库不能作为同一个事务：若文件上传成功但数据库写入失败，工具会输出文件 ID，可修复问题后运行相同命令重试；不会自动删除已上传的文件。

批量处理 Web 的 193 个单词库和两个短语库，可先执行 `npm run upload:dictionary -- --all` 预览，再加 `--upload` 上传。工具会先校验全部文件，再逐个上传；如果中途失败，此前成功上传的文件仍保留在云端。

通过此工具上传才会登记数据库，直接在控制台上传不会自动登记。登记成功后，小程序刷新“全部题库”即可读取。以前的单词进度依赖题库 ID 和条目顺序，恢复旧题库时应保持二者一致。可运行 `npm run test:dictionary-upload` 验证上传工具。

## 进度与故障处理

此前在线题库的学习记录保留在本机；对应题库暂时不显示，后续恢复时可继续使用相同题库标识的记录。

存储键为 `sentleap:miniprogram:v1`，与 Web 数据独立。题库位置、已完成题目、错题、设置和每日记录保存在当前设备。首次掌握获得 10 XP，首次无错误且未使用提示获得额外 5 XP；重复完成不重复发放 XP。离开未完成题目后，从该题开头继续。

本地存储读取失败时保留旧记录，不覆盖损坏数据，并提示本次仅临时保存。写入失败会提示检查空间，内存中仍能继续练习；重新打开不保证保留未成功写入的数据。

## 验证

在仓库根目录执行 `npm run typecheck:miniprogram`、`npm run test:miniprogram` 和 `npm run test:dictionary-upload`。这些检查使用 Node 模拟微信 API，不能替代开发工具编译和真机测试。

真机验收重点：

- 320 / 375 / 430px 宽度、长题目、长单词、横竖屏 / 安全区与自定义胶囊避让。
- iOS 和 Android 内置毛玻璃键盘连续输入、大小写、删除、自动切词及长句滚动。
- 提示、错误、跳过进入错题；无提示正确复习后移除；返回再进入恢复题目位置。
- 断网下三个内置测试库可练；发音需要云托管服务、上游服务和网络。
- 关闭重开后进度和输入统计保留，存储异常显示提示。
- 统计页的非零圆环、周柱状图和海报预览；首页、统计、我的、错题之间导航。
