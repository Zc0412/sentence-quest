# SentLeap 微信小程序

原生 JavaScript + WXML + WXSS，无第三方运行时依赖。导入本目录即可预览，不需要构建 npm。

## 界面与页面

- 题库：首页按 `LibraryGlass.dc.html` 的毛玻璃设计实现，显示真实的当前题目与掌握进度，保留精选短语和句子闯关两个离线库。
- 练习：按 `MainGlass.dc.html` 实现彩色背景、字母方格、音标、英美音切换、XP、掌握率与毛玻璃键盘。内置键盘支持大小写和删除，拼对自动切词；提供提示、跳过、上一句/下一句和完成解析。长句区域独立滚动，键盘固定底部并预留安全区。
- 统计：按 `StatsGlass.dc.html` 实现两个词库的总掌握率、累计 XP、输入数、正确数、正确率和本周（周一至周日）的练习柱状图。生成海报后打开图片预览，由用户自行保存或分享。
- 错题：自动收录拼错、提示和跳过的题目；独立正确完成复习后移除。可通过原生底栏进入。
- 我的：按 `MyGlass.dc.html` 实现资料卡、连续练习天数、真实 XP / 掌握数 / 正确率及毛玻璃设置列表。昵称可编辑并保存在本机；支持发音口音、0.8 / 1 / 1.25 倍速、每日目标、切词后自动发音、字母提示、错题入口及微信原生意见反馈。学习提醒尚未接入订阅消息，保持关闭并说明当前限制。

首页、练习页、统计页与我的页使用自定义导航避让微信胶囊；首页、统计页与我的页使用悬浮底栏，离开后恢复原生 TabBar。输入统计从此版本开始记录到本地，不推算旧版输入历史；每个新增或替换的字符计一次，按对应位置判定正确，删除、字母提示不计数。练习页显示本次练习的统计，统计页显示累计值。

## 导入与联网

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/`。
2. 本地体验可使用默认测试配置；真机预览 / 上传请在 `project.config.json` 使用你自己的小程序 AppID。
3. 内置三个离线测试词库：精选短语（20 题）、句子闯关（11 题）和单词测试（cat、dog、sun）。所有题目随包提供，不请求在线题库。`npm run sync:miniprogram` 同步这三个词库，单词测试复用 Web 的 `public/dictionaries/words/vocabulary-dev-test.json`，支持单词练习、英美音、错题复习与进度统计。
4. 如需在线发音，部署 `../web`，在 `config.js` 填写 `apiBaseUrl: 'https://你的域名'`，不要填 API 路径，不要填写密钥。
5. 微信公众平台服务器域名中配置该域名的 **request** 和 **downloadFile** 合法域名（用于在线发音能力）。保持开发工具 `urlCheck` 开启；不需要配置 web-view 业务域名。
6. 服务需要提供 `/api/pronunciation?word=...&type=1`，均复用现有 Web 实现。口音 `1` 为英音，`2` 为美音。无服务域名时会明确提示，内置练习不受影响。

发音能力依赖现有 Web 服务和上游音频可用性。未配置任何生产地址或 AppSecret。尚未提供登录、云同步、订阅消息提醒和网页端完整分类 / 分组管理界面。自动发音在未配置服务域名时静默跳过；手动点击发音会提示配置域名。

## 进度与故障处理

旧版本其他词库的学习记录保留在本地，但不再显示其错题或进入复习；继续练习会回退到精选短语。

存储键为 `sentleap:miniprogram:v1`，与 Web 数据独立。题库位置、已完成题目、错题、设置和每日记录保存在当前设备。首次掌握获得 10 XP，首次无错误且未使用提示获得额外 5 XP；重复完成不重复发放 XP。离开未完成题目后，从该题开头继续。

本地存储读取失败时保留旧记录，不覆盖损坏数据，并提示本次仅临时保存。写入失败会提示检查空间，内存中仍能继续练习；重新打开不保证保留未成功写入的数据。

## 验证

在仓库根目录执行 `npm run test:miniprogram`。这些检查使用 Node 模拟微信 API，不能替代开发工具编译和真机测试。

真机验收重点：

- 320 / 375 / 430px 宽度、长题目、长单词、横竖屏 / 安全区与自定义胶囊避让。
- iOS 和 Android 内置毛玻璃键盘连续输入、大小写、删除、自动切词及长句滚动。
- 提示、错误、跳过进入错题；无提示正确复习后移除；返回再进入恢复题目位置。
- 断网下两个词库均可练习；发音仍需要真实 HTTPS 服务和网络。
- 关闭重开后进度和输入统计保留，存储异常显示提示。
- 统计页的非零圆环、周柱状图和海报预览；首页、统计、我的、错题之间导航。
